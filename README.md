# Ollama Tutorial

A hands-on tutorial for learning local Large Language Models (LLMs)
using Ollama, Python, embeddings, RAG, tool calling, and FastAPI.

## Prerequisites

- Linux, macOS, or Windows with WSL
- Python 3.11 or newer
- Ollama installed and running
- Sufficient RAM or GPU memory for your chosen model

## Project Structure

- `docs/`: Documentation and architecture references
- `tutorials/`: Step-by-step learning modules
- `src/`: Reusable application code
- `projects/`: Practical projects
- `tests/`: Unit, integration, and evaluation tests
- `benchmarks/`: Model performance benchmarks

and follow each sprint in sequence.
