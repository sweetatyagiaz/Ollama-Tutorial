# Ollama Tutorial

A hands-on tutorial for learning local Large Language Models (LLMs)
using Ollama, Python, embeddings, RAG, tool calling, and FastAPI.

## Learning Roadmap

| Sprint | Topic |
|---|---|
| 1 | Ollama Fundamentals and Environment Setup |
| 2 | Python Integration and Chat Applications |
| 3 | Model Selection and Performance Optimization |
| 4 | Embeddings and Semantic Search |
| 5 | Retrieval-Augmented Generation (RAG) |
| 6 | LangChain, Tool Calling, and AI Agents |
| 7 | FastAPI and Production Engineering |
| 8 | Enterprise Knowledge Assistant Capstone |

## Prerequisites

- Linux, macOS, or Windows with WSL
- Python 3.11 or newer
- Ollama installed and running
- Sufficient RAM or GPU memory for your chosen model

## Getting Started

Follow the Sprint 1 installation guide:

[Installation Guide](docs/installation.md)

## Project Structure

- `docs/`: Documentation and architecture references
- `tutorials/`: Step-by-step learning modules
- `src/`: Reusable application code
- `projects/`: Practical projects
- `tests/`: Unit, integration, and evaluation tests
- `benchmarks/`: Model performance benchmarks

## Development

Create and activate a Python virtual environment, install the dependencies,
and follow each sprint in sequence.
